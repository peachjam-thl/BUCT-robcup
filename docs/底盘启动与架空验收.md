## 当前结论

已打通 USB SSH → ROS2 `/cmd_vel` → 串口驱动 → 控制板反馈。x/y 测试中用户确认四轮响应并停转；yaw 有角速度反馈、结束反馈归零，实际四轮停转待单独确认。测试按四轮架空要求进行，未验收地面方向、距离、角度和里程计精度。

独立指令超时、物理断线、计算板掉电或进程强杀时的停车尚未实测。收到零速后停止，不能证明断流也会停止。

## 架空运动测试

使用 [base_forward_probe.py](../tools/base_forward_probe.py)，每次前置 1 s 零速，结束尝试连续 2 s 零速。

| 命令参数 | 反馈和用户观察 | 结论 |
| --- | --- | --- |
| x=0.03 m/s，1 s | 多次全零，四轮没动 | 首次电机响应未通过 |
| x=0.05 m/s，1 s | 独立 echo 捕获 linear.x=0.05、其余为零；短暂转动，打印反馈仍零 | 有动作，反馈尚不足 |
| x=0.05 m/s，3 s | 初段零；vx≈0.025–0.065，vy≈−0.007–0.021，wz≈−0.072–0.090；最后全零 | 用户确认四轮均转动并停下 |
| y=0.05 m/s，3 s | vy≈0.034–0.061，伴有其他轴小幅反馈及瞬态 wz≈0.104；最后全零 | 用户确认四轮均响应并停止 |
| yaw=0.15 rad/s，3 s | 前约 2 s 零，后 wz=0.151、0.125、0.192、0.150；vx 最高约 0.015、vy 约 0.026；最后全零 | 对应角速度反馈已观察，实际四轮停转待单独确认 |

初段零反馈原因未定位，不据此认定低速死区或固定延迟。架空跨轴波动不代表地面漂移或里程计误差，不据此直接调比例。

## 复现

车体稳固、四轮离地，避免滚轮夹点，电机电源停止方式可触及。驱动终端保持运行；不要同时启动遥控、导航或第二个底盘驱动。

Windows PowerShell：

```powershell
scp "D:\Personal\Desktop\LETSROS\tools\base_forward_probe.py" wheeltec@192.168.128.10:/tmp/base_forward_probe.py
```

第二处小车 SSH shell，逐条运行，每次确认停转后继续：

```bash
python3 /tmp/base_forward_probe.py --axis x --speed 0.05 --duration 3
python3 /tmp/base_forward_probe.py --axis y --speed 0.05 --duration 3
python3 /tmp/base_forward_probe.py --axis yaw --speed 0.15 --duration 3
```

默认 x/0.03 m/s/1 s；x/y 上限 0.05 m/s、yaw 上限 0.15 rad/s、时长≤3 s。脚本等待新鲜里程计与订阅者，检测竞争发布者；在反馈过期、用户中断等退出路径尝试发零速。这些检查依赖 ROS 图和消息接收，不能代替物理停止及 MCU 保护。

## 已准备但未实测：指令断流检查

默认关闭，仅 x 轴。以下命令尚未在车上执行：

```bash
python3 /tmp/base_forward_probe.py --axis x --speed 0.05 --duration 3 --check-silence-stop
```

正常命令阶段后暂停发布速度消息，自最后一条非零命令起最多观察 1.5 s，再尝试零速兜底。开始时须反馈新鲜且 vx>0.02 m/s；近零判据为 |vx|、|vy|≤0.01 m/s 且 |wz|≤0.04 rad/s，需持续接收至少 0.20 s。

- SILENCE_STOP_OBSERVED：满足近零反馈，仍须观察四轮是否在零速兜底前停转；时间仅为接收时刻估计。
- SILENCE_STOP_NOT_OBSERVED：窗口内未见稳定近零，不排除更长固件超时，不能记为保护通过。
- SILENCE_CHECK_INVALID 或其他中断：条件不足或检查终止，不作停车结论。

1.5 s 是脚本观察限制，非厂家指标或比赛标准。本测试不等于物理拔线、掉电或强杀进程；仍须架空且能立即切断电机电源。
