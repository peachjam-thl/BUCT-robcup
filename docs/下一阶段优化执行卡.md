# 下一阶段优化执行卡

更新日期：2026-11-19。本文是后续执行计划，不增加实测成果；当前仍暂停实车测试。当前证据见[两日阶段总结](2026-11-18_19阶段总结.md)，长期安排见[执行计划表](../执行计划表.md)。

## 阶段目标

先形成可重复演示的“建图 → 到点 → 识别指定二维码 → 报告有效目标位置”流程，再在此基础上扩展数字标签与实物识别。二维码只是首个闭环的优先对象，正式比赛的其他任务仍保留在计划中。

目前底盘已有三轴架空响应，新门控有基本流程证据；雷达已有消息、RViz显示及实物变化响应。下一阶段优先补齐真实距离、方向、坐标关系和模块连接，逐项留下可复现成果。

| ③ 底盘地面验证 | 物理停止方式、指令时效保护及相应停止条件确认后，验证前后、横移、转向和实际位移；继续追溯MCU独立超时 | 方向/单位与里程计误差记录；停止保护证据 | 尚未放行地面自动运动 |

| 优化 | 接下来做什么 | 完成标准 / 当前边界 |

## 下一次到车旁的第一项

携带卷尺和纸箱/竖直纸板，按[雷达静态验收](雷达静态验收.md)恢复雷达显示；先查现有节点，保持底盘静止。实测雷达扫描中心到箱面的距离，核对明确朝向下的回波，记录安装高度与遮挡；随后保存RViz配置。先交回距离对照、截图和配置文件，再决定下一项。

系统维护单独安排：RTC保持问题继续保留；建图前核对本轮时间戳与TF的一致性，采集中发生时钟跳变则暂停并复查。重启、软件包修改与实车功能测试分开进行，不在本执行卡中追加系统升级或时间服务替换。
