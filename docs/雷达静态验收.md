## 已跑通：在小车桌面显示原始扫描

保持雷达SSH终端运行、小车静止；不启动底盘。使用小车屏幕桌面上的终端运行GUI，避免普通Windows SSH没有图形显示环境的问题：

```bash
source /opt/ros/humble/setup.bash
source ~/wheeltec_ros2/install/setup.bash
ros2 run rviz2 rviz2
```

在RViz左侧Displays：

1. Global Options → Fixed Frame填写laser，与收到的LaserScan header一致。这一阶段只观察雷达自身坐标，不用map或base_footprint。
2. Add → By display type → LaserScan → OK。
3. 展开LaserScan，Topic选择/scan；展开Topic后将Reliability Policy设为Best Effort，Durability Policy保持Volatile。
4. 保持车不动，观察墙是否形成相应轮廓，以及人在旁边走动时扫描点是否跟随改变；截图并描述真实环境。

Humble字段核对：[Nav2官方RViz配置中的LaserScan](https://github.com/ros-navigation/navigation2/blob/humble/nav2_bringup/rviz/nav2_default_view.rviz)。这里只采用显示方式，不启动Nav2或使用其默认map坐标。

如果GUI打不开，保存终端错误，不修改系统图形驱动。若画面空白或状态报错，发截图及LaserScan状态信息；不添加虚假的map/odom静态TF来消除提示。

## 随后仍需检查

恢复后先做第一项：保持小车不动，在明确朝向放置纸箱/竖直纸板，覆盖雷达扫描高度，量取扫描中心到箱面距离并记录。RViz添加Axes，Reference Frame设为laser，Length可先用0.5、Radius用0.01；拍下坐标轴与回波并记录箱子位于车体哪侧，再对照实际方向与距离。该Axes配置及距离核对尚未收到实车结果，不能记为完成。

- 按雷达实际扫描中心量已知墙距，与消息距离/可视化对照；先明确坐标轴，再验证方向。
- 测扫描平面离地高度，核对比赛围墙和家具是否进入该平面；记录机体、支架、线缆遮挡。
- 检查有效距离比例、无效值和角度范围，不在终端倾倒全部ranges。
- 确认安装外参和唯一TF发布者后，再接到车体/里程计链路。当前frame=laser的显示不证明base到laser已正确。
