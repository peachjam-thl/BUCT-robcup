# BUCT-robcup ｜ RoboCup 家庭服务机器人（校赛）

北京化工大学智能服务机器人大赛 / RoboCup 机器人世界杯中国赛 家庭组项目校赛。

车辆自行组装。比赛场地为 4 个房间、约 70 ㎡，门宽 65–90 cm，任务前有 30 分钟建图时间；任务是从入口出发，到指定点寻找目标（二维码、二维码样式数字标签、真实物品），示意找到并报告目标位置。

## 安全与保密

- 本仓库不记录登录密码、Wi-Fi 密码、访问令牌或云服务密钥。
- 不提交厂商闭源固件、镜像文件与个人隐私数据；需要时只记录版本号与来源链接。
- 涉及电机的测试必须在轮子离地或空旷受控场地进行，并确认急停/断电方式有效。
