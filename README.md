# BUCT-robcup ｜ RoboCup 家庭服务机器人（校赛）

北京化工大学智能服务机器人大赛 / RoboCup 机器人世界杯中国赛 家庭组项目校赛。

车辆自行组装。比赛场地为 4 个房间、约 70 ㎡，门宽 65–90 cm，任务前有 30 分钟建图时间；任务是从入口出发，到指定点寻找目标（二维码、二维码样式数字标签、真实物品），示意找到并报告目标位置。

## 队友从这里接手

**截至 2026-11-19：实车测试暂停，进度停在 D5 雷达静态验收。** N10P 已发布约 10.04 Hz 的 `/scan`，RViz 有回波，用户确认移动实物时轮廓有变化。恢复后先核对已知距离、朝向和安装高度，再整理实际 TF；尚未建图。

昨天 D3 新门控 x 轴架空基本流程已验证：授权运动、断流停转（近零反馈约 0.986 s）、锁定、未授权请求反馈零、手动重授权恢复及再次停转（约 1.033 s）。两次断流均有兜底前停转目视确认；其他故障和 MCU 独立超时未整体验收，地面自动运动尚未放行。完整交接见 **[11月18—19日阶段总结](docs/2026-11-18_19阶段总结.md)**。

## 工具脚本

**板端体检**（USB 已连好时，在仓库根目录执行一条命令，密码输入一次）：

```powershell
Get-Content .\tools\board-check.sh -Raw | ssh wheeltec@192.168.128.10 'bash -s'
```

脚本只读，不改配置、不需要 root。输出较长，建议重定向存档：

```powershell
Get-Content .\tools\board-check.sh -Raw | ssh wheeltec@192.168.128.10 'bash -s' | Tee-Object -FilePath .\tmp\board-check.txt
```

**电脑侧自检**（板卡 ping 不通时先跑这个）：

```powershell
powershell -NoProfile -File .\tools\pc-link-check.ps1
```

**架空测试留证**（四轮离地、能立即断电时）：给 `base_forward_probe.py` 加 `--confirm-wheel-stop` 记录操作员对停转的判断，加 `--check-silence-stop` 做断流观察，`--log-csv` / `--evidence-out` 留下时序与可粘贴证据。完整步骤见 [停转确认与指令断流执行卡](docs/停转确认与指令断流执行卡.md)。

**底盘统一入口：** 先读 [D3门控与统一启动](docs/D3门控与统一启动.md)，按静态检查、架空授权的顺序执行。旧看门狗仅保留历史记录，不能与新入口并用；不要照旧记录直接启动第二套驱动或增加 `--watchdog`。

## 安全与保密

- 本仓库不记录登录密码、Wi-Fi 密码、访问令牌或云服务密钥。
