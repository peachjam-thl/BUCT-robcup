# BUCT-robocup ｜ RoboCup 家庭服务机器人（校赛）

WE WILL MAKE IT MAYBE.
北京化工大学智能服务机器人大赛 / RoboCup 机器人世界杯中国赛 家庭组项目校赛。

车辆自行组装。比赛场地为 4 个房间、约 70 ㎡，门宽 65–90 cm，任务前有 30 分钟建图时间；任务是从入口出发，到指定点寻找目标（二维码、二维码样式数字标签、真实物品），示意找到并报告目标位置。

## 队友从这里接手

**截至 2026-11-23：第一份场地地图已保存，地图重载与 AMCL 定位已验证，Nav2 单点去程和返程两次均成功。** 地图为435×680栅格、0.05 m分辨率；激光与地图静止对齐检查为88.3%（0.15 m容差）。短路径规划约0.82 m，记录的到达估计位姿与目标距离约0.05 / 0.15 m。以上是本次有限测试结果，不是整场导航、绝对定位精度或完整停车保护验收。证据入口：[当日日志](日志/2026-11-23.md)、[地图及定位](maps/2026-11-23/README.md)、[Nav2验证](docs/Nav2单点导航验证.md)。

**下次先读本页、[11月23日日志](日志/2026-11-23.md)和[Nav2验证记录](docs/Nav2单点导航验证.md)，从D12后半的取消/停稳验证接续。** 先确认本轮供电、连接地址、时间和现有节点。远程ROS命令显式设置`ROS_DOMAIN_ID=10`；现场曾用共同手机热点，地址会随DHCP变化。最后结果是导航往返成功，未记录之后的完整收尾清单，不能沿用11月21日“节点为空、四轮架空”的状态。

## 工具脚本

**板端体检**（USB 已连好时，在仓库根目录执行一条命令，密码输入一次）：

```powershell
Get-Content .\tools\board-check.sh -Raw | ssh wheeltec@192.168.128.10 'export ROS_DOMAIN_ID=10; source /opt/ros/humble/setup.bash; source ~/wheeltec_ros2/install/setup.bash; bash -s'
```

